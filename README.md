Этот репозиторий содержит коллекцию проектов и утилит для работы с LoRa трансивером **LR1121** (включая модули на базе **LILYGO T3-S3**). Главным направлением проекта является тестирование, симуляция и работа с радиопротоколом **ExpressLRS** как на частоте 2.4 ГГц, так и в Sub-GHz диапазонах (868 МГц), а также передача файлов и телеметрии.

## 🌟 Ключевые фичи (Features)

*   **Мультидиапазонная поддержка**: Работа как в 2.4 GHz ISM-диапазоне, так и на 868 MHz (Sub-GHz) благодаря чипу LR1121.
*   **Симуляция ExpressLRS**: Реализация протокола управления для 4 ролей: Pilot, Drone, Aggressor, Monitor.
*   **Адаптивный FHSS**: Механизм псевдослучайной перестройки рабочей частоты (FHSS) для синхронизации и защиты от помех (как в оригинальном ELRS).
*   **Управление RF-свитчами**: Поддержка управления антенными переключателями (SKY13351) для корректной работы RX/TX путей на платах LILYGO T3-S3.
*   **Многомодульная архитектура**: Один проект PlatformIO содержит все необходимые примеры: от простого пинг-понга до передачи файлов и перехвата (Disarm) пакетов.

## 📂 Структура репозитория

Для удобства использования и поддержки проект организован по стандартам PlatformIO / Embedded C++:

*   `/src/` — Исходный код (содержит подпапки для каждого "примера" прошивки).
*   `/src/*/include/` — Общие заголовочные файлы, конфигурации пинов (`pins_config.h`), данные для тестов (`file_data.h`) для каждого проекта.
*   `/docs/` — Документация, PDF-схемы (T3-S3), даташиты на трансивер LR1121, статьи по электронике.
*   `/lib/` — Локальные библиотеки (при необходимости).
*   `/hardware/` — Директория для файлов печатных плат (KiCad, Gerber).

## 🚀 Начало работы (Getting Started)

### 1. Клонирование репозитория
Склонируйте проект на свой локальный компьютер:
```bash
git clone https://github.com/your-repo/lora-lr1121.git
cd lora-lr1121
```

### 2. Подготовка среды (VS Code + PlatformIO)
1. Установите [Visual Studio Code](https://code.visualstudio.com/).
2. Установите расширение **PlatformIO IDE** из магазина расширений VS Code.
3. Откройте папку проекта `lora-lr1121` в VS Code. PlatformIO автоматически распознает файл `platformio.ini` и начнет скачивать необходимые зависимости.

### 3. Выбор проекта и прошивка
Проект содержит несколько конфигураций (Environments). По умолчанию собирается `env:disarm_erls_monitor`.
Чтобы выбрать другую прошивку:
1. Внизу окна VS Code на панели PlatformIO нажмите на название текущего окружения (например, `Default (disarm_erls_monitor)`).
2. Выберите нужное окружение из списка (например, `env:disarm_erls_pilot` или `env:lrr_868_ping_pong_master`).
3. Подключите плату ESP32 (LILYGO T3-S3) по USB.
4. Нажмите кнопку **Upload** (иконка стрелочки вправо на нижней панели) для компиляции и прошивки.

## 🔌 Схема подключения (Hardware Setup)

Код из коробки настроен под плату **LILYGO T3-S3 v1.2** с чипом LR1121. Все конфигурации пинов находятся в файлах `pins_config.h` внутри соответствующих проектов.

**Основные подключения SPI (внутренние для T3-S3):**
*   `SCK` : GPIO 5
*   `MISO`: GPIO 3
*   `MOSI`: GPIO 6
*   `CS`  : GPIO 7
*   `RST` : GPIO 8
*   `DIO9` (IRQ): GPIO 36
*   `BUSY`: GPIO 34

**Управление антенным переключателем:**
*   `ANT_SW_VDD`: GPIO 21
*   `ANT_SW_TX`: GPIO 9
*   `ANT_SW_RX`: GPIO 10

**I2C Дисплей (OLED SSD1306):**
*   `SDA`: GPIO 18
*   `SCL`: GPIO 17

*Подробные схемы платы (PDF) можно найти в папке `/docs/`.*
